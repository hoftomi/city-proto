# MapRoute

Útvonal földútként, tintakontúrral és kavicsszaggatással.

**Mit ad a hívó:** `from`, `to`, `state`, `tincture`.

- `base`: halvány földút.
- `own`: széles bronz út.
- `pending`: szaggatott bronz út.
- `rival`: a ház színe.
- `blocked`: vörös, tiltójellel.
- `closed`: szürke szaggatott.
