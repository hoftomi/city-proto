# SuspicionMeter

Egy frakció gyanúja a szereplővel szemben (0–3), a hatással együtt.

**Mit ad a hívó:** `value` (0–3), opcionálisan `showEffect={false}`, ha nincs hely a hatás szövegének.

- 1–2: `warn`, 3 (Kiűzetés): `danger`. A szem-ikonok száma színtévesztő játékosnak is olvasható.
- A hatásszöveg a szabálykönyv 9.3. pontját követi. Ha a számok változnak, itt is frissíteni kell.
