# NavBar

Alsó navigáció sötét fán, bronz felső szegéllyel. Minden fül játékikont kap. A kijelölt fül ikonja bronz keretes, izzó mezőbe kerül, a felirata bronz lesz.

**Mit ad a hívó:** `items` (`[{id, label, icon, art?, badge?}]`), `active`, `onChange`.

- Az `icon` név automatikusan játékikonra fordul: `terkep`, `varos`, `kem`, `pp`, `legit`.
