# ReportCard

Jelentés levélpapíron: vékony fakeret és bronz belső vonal. A fejlécet hajszálvonal választja el a szövegtől.

**Mit ad a hívó:** `kind`, `confidence`, `tick`, `title`, `children`, `footer`.

- A típus nagybetűs címke, pecsétviasz színű ikonnal. A cím Cinzel betűs, a szöveg Nunito Sans.
