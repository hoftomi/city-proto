# HouseCrest

Egy hatalmi ház címere: pajzs a ház tinktúrájával és kezdőbetűjével.

**Mit ad a hívó:** `tincture` (`voros` | `kek` | `zold` | `arany` | `bibor` | `fekete` | `narancs` | `szeder`), `initial`, `name` (a képernyőolvasónak), `npc`, `size` (alapérték 28).

- NPC-ház címerének szaggatott a kontúrja. Ezt a listákban mindig egészítsd ki az „NPC” szóval.
- A tinktúra a ház színe mindenhol: befolyássávon, térképen, útvonalon.
