# SuspicionMeter

A faction's suspicion toward the actor (0–3), together with its effect.

**What the caller provides:** `value` (0–3), optionally `showEffect={false}` if there is no room for the effect text.

- 1–2: `warn`, 3 (Banishment): `danger`. The number of eye icons is readable for color-blind players too.
- The effect text follows section 9.3 of the rulebook. If the numbers change, it has to be updated here as well.
